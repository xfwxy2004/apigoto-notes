# More agent tools supported in APIGOTO

- **Codex** — code generation, refactoring, test writing.
- **Claude** — long-context reasoning, document review.
- **Hermes** — local multi-step agent orchestration.
- **OpenClaw** — GitHub issue → project pipeline.

Each agent gets its own workspace pane. API keys are configured once in the gateway and inherited. Model switching is a config change.
