# APIGOTO desktop client just shipped

A single window for agents, tools, and 200+ models.

## What's in the box

- **Agents**: Codex, Claude, Hermes, OpenClaw — each in its own pane.
- **Tools**: MCP servers, plugins, workflow editors.
- **Models**: 200+ LLMs behind one gateway.

## Why one client

The setup I used to do weekly now takes 5 minutes. No more tab-switching. No more rebuilding the same base URL / API key / auth header.
